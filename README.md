# Observatorio del Voto

Dashboard de encuestas nacionales de intención de voto en España para el 29N.

## Publicación

Este repositorio está preparado para GitHub Pages. En Settings > Pages selecciona Deploy from a branch, main y /(root).

## Archivos

- index.html, styles.css, app.js: sitio web.
- data/polls.json: sondeos editables.
- data/polls.js: copia de datos utilizada por la aplicación.
- scripts/sync-data.py: sincroniza los datos.
- .github/workflows/validate.yml: comprobaciones.
- CHANGELOG.txt: historial.

## Metodología

Media descriptiva de los sondeos disponibles; no es un pronóstico electoral. Los datos y sus fuentes deben verificarse periódicamente.
